Viz API reference

With Auto-visualize on, write plain loops/comparisons for any structure — visualization triggers automatically on Run.

  • await viz.step({ message, line, highlights, pointers, variables }) — record & pause
  • viz.setArray(arr) / viz.setString(s) / viz.setGraph(grid) / viz.setTree(root)
  • viz.setArrayView('bars'|'cells'|'both') — array display mode
  • viz.highlight(indices, type) — index highlights: compare, swap, found, visited, match, mismatch
  • viz.highlightRange(start, end, type) — highlight a substring / subarray range
  • viz.setPointers({ left, right, i, j, ... }) — named pointer labels
  • viz.highlightNodes([nodeIds]) / viz.highlightCells([[r,c],...])
  • viz.setVariables({ key: value }) — show in variables panel
  • log(...args) — append to console output
