# study_code — read drill CLI

This folder runs the **code reading** workflow. Practice files are in [`../drills/read/`](../drills/read/).

## Commands

```bash
go run .              # today's reading drill plan
go run . -- --run     # check filled answers
go run . -- --micro   # Core Read 3 only
```
