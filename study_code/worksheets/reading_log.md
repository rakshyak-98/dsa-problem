# Reading session log (optional)

One line per session. Copy forward.

```
YYYY-MM-DD | core OK/FAIL | specialty | one miss | revisit date
```

Examples:

```
2026-07-29 | core OK | 01_scan_structure | called snip1 return "value" | 2026-08-01
2026-07-30 | core OK | 02_trace_execution | wrong mid sequence on BS | 2026-08-02
```
