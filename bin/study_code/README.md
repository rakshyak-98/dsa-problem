# study_code — read drill CLI

Internal tooling for the **code reading** workflow. Practice files are in [`../../drills/read/`](../../drills/read/).

## Commands (from repo root)

```bash
go run ./bin/study_code              # today's reading plan
go run ./bin/study_code -- --run     # check answers
go run ./bin/study_code -- --catalog # full catalog
go run ./bin/study_code -- --drill core   # core read only
```
